📘 如何配置真正的外部数据源

当前 demo 模式下「联网刷新」仅写入一条演示数据。

要让真题/岗位真正实时联网：
1. 准备一个返回 JSON 数组的 HTTPS 接口（可用 GitHub Pages / CloudBase 等）：
  https://your-domain.com/exams.json（数组，每项含 id/title/content/subject/year）
2. 启动 server.js 时传入环境变量：
  set EXAMS_SOURCE=https://your-domain.com/exams.json
  set JOBS_SOURCE=https://your-domain.com/jobs.json
  node server.js
3. 在本后台「联网刷新」按钮即可拉取并去重写入。

长期建议：把采集脚本挂到云函数 / GitHub Actions，定时把官方源数据 dump 到 JSON，再让本后台拉取。
