# 帮帮林 · 考研·就业全周期规划

> 一款面向本科生升学与就业的智能化学习管理工具。**双端口架构 + 统一登录**：用户端 `localhost:3210`、管理端 `localhost:3211/admin`——全应用只有一个登录界面，使用管理员账户登录后会出现「进入客户端 / 进入管理端」二选一按钮；普通账户直接进入客户端。

[在线体验](https://408kaoyan-workbench.vercel.app)

---

## 桌面 exe 使用（无需命令行）

本文件夹即为可独立运行的桌面软件，**双击 `帮帮林.exe` 即可**：后台会自动用自带的 `node.exe` 启动服务，并在默认浏览器打开用户端 `http://localhost:3210`。

- 管理员账户 `2815097621@qq.com` 登录后，会看到「进入客户端 / 进入管理端」二选一。
- 管理端地址：`http://localhost:3211/admin`（需先以管理员身份登录）。
- 停止服务：双击本文件夹内的 `停止帮帮林.bat`，或在弹窗中点确定后于任务管理器结束 node 进程。
- 整个 `帮帮林` 文件夹可整体复制到其他电脑使用（请保持 `帮帮林.exe` 与 `node.exe` / `server.js` / `index.html` 等同级）。

## 软件简介

围绕「考研」与「就业」两条发展路线，为用户提供个性化的每日学习计划、长期备考日历、各科目进度跟踪、真题与题库训练、简历与面试辅助，以及周 / 月学习复盘等一体化功能，帮助用户科学规划、持续执行、及时回顾。

## 功能概览

### 核心功能

| 模块 | 说明 |
|------|------|
| 每日计划 | 根据备考阶段与用户档案动态生成每日计划，含时间点、课程内容、时长；支持完成标记与对话式调整 |
| 长期规划日历 | 日历式可视化展示备考全周期，按阶段着色，标注里程碑节点 |
| 用户档案 | 收集本科院校、专业、考研年份、目标等信息，自动生成个性化规划 |
| 英语学习 | 每日单词背诵（List 轮转）、真题阅读训练 |
| 高数学习 | 武忠祥高数基础课 37 集进度跟踪 |
| 408 专业课 | 王道考研四门（数据结构 / 计组 / 操作系统 / 网络）章节轮转 |
| 考研政治 | 政治科目学习模块 |
| 智能健身 | 眼保健操、站立活动等健康提醒 |
| 实习投递 | 企业推荐与投递进度管理 |
| 就业准备 | 生涯规划、简历分析、面试练习、技能证书、求职日历 |
| 周复盘 / 月复盘 | 学习数据回顾与统计 |

### AI 增强功能（**默认支持浏览器内置 AI，零费用、零配置**）

- **浏览器内置 AI（WebLLM）**：默认在本地浏览器内运行 Qwen2.5-1.5B-Instruct 开源大模型，**完全离线、零费用、零密钥**。首次使用需联网下载约 1.2 GB 模型，浏览器缓存后秒开。
- **每题 AI 答疑**：每道例题下方可调用 AI 解答
- **对话式计划修改**：支持自然语言修改学习计划（如「明天有事，从明天起以今天为第1天重新规划」）
- **答错出题**：答错后 AI 自动生成 3 道类似题目
- **拍照 OCR 识别**：各模块支持拍照识别题目 / 笔记（需在线 API：通义千问 / 智谱）
- **可选在线 API**：若本地模型回答不满意，可切换到 DeepSeek / Qwen / 智谱 公开服务（需自备 API Key，可能产生费用）

### 其他特性

- **🔁 「以今天为第1天重新规划」**：一键重置基础日、清空未来计划、让所有阶段重新铺排。适合前几天因事没学、需要"重新起跑"的场景

- **自适应深色 / 浅色主题**
- **响应式布局**，手机 / 平板 / 电脑均可用
- **内置免责声明与用户承诺书**
- **无需注册**即可使用全部核心功能

## 技术栈

- **纯 HTML + CSS + JavaScript**（单文件 `index.html`，约 8000 行）
- **localStorage** 本地数据持久化
- **AI 引擎**：[WebLLM](https://github.com/mlc-ai/web-llm)（浏览器内置 AI，[Qwen2.5-1.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct) 模型）
- **可选**：Node.js 后端 `server.js`（零依赖，云端账号与数据同步）
- **可选**：DeepSeek / Qwen / 智谱 等大模型 API（在线 AI 备选，需自备 Key）
- 无构建工具、无前端依赖

## 重新规划（以今天为第1天）

> 适用场景：前几天因请假、出差、临时有事落下了，重新打开工作台后希望把"今天"作为新的第1天铺排剩余计划。

### 用法
1. 进入「每日计划」页面
2. 点击顶部「🔁 以今天为第1天重新规划」按钮
3. 确认 → 历史已完成的任务保留；未来 14 天的计划根据当前阶段模板重新铺排

### 自动顺延
- 当你 **连续 ≥ 2 天** 没打开工作台，再次打开时会自动将过往未完成的学习/运动任务顺延到今天（防止你漏掉重要任务）
- 如果"自动顺延"不是你想要的，点「不想顺延？点此重置」按钮即可一键重置

## AI 功能配置

### 模式一：浏览器内置 AI（**默认推荐**，零费用）

1. 打开工作台 → 点击右下角 AI 浮动按钮
2. 点击「⚡ 启用本地 AI」或「启用浏览器内置 AI」
3. 首次启动会下载约 1.2 GB 模型（仅首次，之后秒开）
4. 下载完成后，所有 AI 对话均在本机完成，无任何外发

> **要求**：Chrome / Edge 113+ 浏览器，且浏览器需支持 WebGPU。Firefox / Safari 当前暂不支持 WebGPU，请用模式二。

### 模式二：在线 API（备选）

如不愿/不能在本地下载模型，可使用在线 API：

| 服务商 | 获取方式 | 备注 |
|------|------|------|
| DeepSeek | <https://platform.deepseek.com> | 文本，便宜稳定 |
| 通义千问 (Qwen) | <https://dashscope.aliyun.com> | 支持图片分析 |
| 智谱 AI (GLM-4) | <https://open.bigmodel.cn> | 支持图片分析 |

在「设置」页面填入 API Key 即可启用；不配置也能使用浏览器内置 AI 或离线规则引擎。

### AI 来源与免责

点击 AI 面板 / 设置中的「ℹ️ 关于 AI」按钮查看完整说明，包括：
- 模型的训练方、版本号、许可证、官方仓库链接
- 完整的 7 条免责申明（择校/报考/健身等）
