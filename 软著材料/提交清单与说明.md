## 二、技术形态

| 项目 | 内容 |
|---|---|
| 软件类型 | Windows 桌面可执行程序（PyInstaller 打包，内置 Node.js 运行时） |
| 部署平台 | Windows 7 及以上（已在 Windows 11 验证） |
| 主技术栈 | Node.js 22（零第三方依赖后端）· 原生 JavaScript(ES5) 前端 · Python+PyInstaller 打包 |
| 源代码行数 | 约 9000 行（含 HTML/CSS/JS，不含内置 Node 运行时） |
| 数据存储 | 本机 `./server-data/*.json`（JSON 文件） + 浏览器 localStorage |
| 联网特性 | 用户端 / 管理端双端口 + 匿名报考数据上报 + 可联网拉取真题/岗位 + 可选在线 AI |
| 第三方依赖 | 无运行时第三方依赖；打包阶段用 PyInstaller（MIT） |

## 七、版本迭代说明

如需基于新版本重新生成材料：

```bash
python gen_soft.py          # 重新生成 说明书 + 源程序代码 两个 PDF
python gen_application.py   # 重新生成申请表指南
```

> `gen_soft.py` 会自动读取 `../server.js`、`../launcher.py`、`../admin.html`、`../index.html`，按"前 30 页 + 后 30 页"规则排版。
